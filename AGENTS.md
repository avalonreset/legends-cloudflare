# Agent instructions

Read `docs/AGENT-RECIPE.md`, then `wiki/index.md` and the smallest matching runbook.
Run offline doctor before commands and live doctor before authorized API operations.

- This module is `legends-cloudflare`. The earlier private kit is a separate compatibility surface.
- Read before changing DNS. Require a reviewed plan and the owner's explicit authorization for its zone and record.
- Keep tokens, private inventories and receipts outside this repository and managed installations.
- Do not infer propagation, service health or edit permission from successful reads.
- Preserve the one-skill router. Module recipes are Markdown, not new host skill registrations.
- Use current official Cloudflare sources and date evidence when changing guidance.
- Run offline tests, release checks, and clean installation before release.
- Publication, registrar transfers and production DNS changes are separate actions requiring their actual task authorization.
